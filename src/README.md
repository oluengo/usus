# Usus code

The app is a single page (`index.html` at the root), but it's written in parts here and assembled with:

```
npm run build        # translations (i18n/*.po → js/90-i18n.js) + assembles index.html
```

`index.html` is generated and committed as is (the web app, the APK and the tests use it): **don't edit it by hand**; edit `src/` and build. On every change GitHub checks that it's up to date ("Strings" workflow).

| File | What it is |
|---|---|
| `index.html` | Page skeleton. `/*@css*/` and `/*@js*/` mark where the styles and the code go. |
| `css/*.css` | Styles, in name order: base and themes, catalogue, progression and AI, sharing and diary, editor, 3.0 layout, wide screen, printable. |
| `js/*.js` | Code, in name order. Everything goes inside the same `(() => { … })()` block, so the parts see each other as if they were one file; order only matters for what runs on load (`99-arranque.js` goes last). |
| `js/90-i18n.js` | Translation dictionary. Generated by `scripts/i18n.mjs` from `i18n/*.po`: not edited by hand. |

Code parts (file names in Spanish): `01-base` (utilities, languages, storage, state) · `02-plan` · `03-catalogo` (catalogue) · `04-secciones-grupos` (sections and groups) · `05-progresion` (progression) · `06-ia-csv` (AI and CSV) · `07-esfuerzo-notas` (effort and notes) · `08-iconos-render` (icons and rendering) · `10-hoy-sesion` (Today and session) · `11-foco` (countdown) · `12-rutinas-editor` (routine editor) · `13-imprimir` (printing) · `14-diario-datos` (diary data) · `15-ciclo` (cycle) · `16-actividad-diario` (activity) · `17-progreso` (progress) · `18-ajustes` (settings) · `19-novedades-bienvenida` (what's new and welcome) · `20-compartir` (sharing) · `21-perfiles` (profiles) · `22-acerca` (about) · `23-formato-datos` (data format) · `24-plan-guiado` (guided plan) · `25-nostr` · `30-eventos` (events) · `99-arranque` (startup).

**Nostr:** `nostr.js` (root) is the library used by `25-nostr.js` (NIP-46 bunker, relays): it's generated with `npm run nostr` from `scripts/nostr/entry.mjs` (nostr-tools at a fixed version) and committed. The app only loads it when Nostr is used.

To test: `npm test` (builds before starting; see `tests/README.md`).
